# linklin / PICO Spatial Prompt 模版库

日期：2026-09-25  
目标：沉淀本轮开发中有效的需求表达方式， especially 如何把“普通网页 / 2D 表单 / 平面 UI”的需求，准确描述成 PICO Spatial 里的空间 UI、空间交互和真机可验证结果。

使用方式：将 `{...}` 替换成具体项目内容，并尽量保留“目标 / 约束 / 交互 / 视觉 / 验收标准”五段结构。

## Prompt 6：双手调整面板位置和角度

```text
请为 `{空间面板}` 增加双手直接调整能力。

手势规则：
- 单手捏住并拖动：只移动面板位置
- 双手同时捏住面板：
  - 双手中心移动 → 面板位置移动
  - 双手连线变化 → 调整面板 yaw / pitch
  - 位置和角度可以同时变化

要求：
- 不使用长按切换模式
- 不显示模式切换按钮
- pitch 限制在 ±45°，避免面板翻到不可读
- yaw 可以完整调整

验收：
- 单手拖动不会误旋转
- 双手同向移动时面板稳定跟随
- 一手向前一手向后可调整左右朝向
- 一手向上一手向下可调整俯仰
```

## Prompt 8：手感模式双卡相碰

```text
请优化 `{手感模式}` 的确认动作。

旧交互：
- 双手拍掌消除

问题：
- 动作尴尬
- 双手靠近时追踪不稳定
- 用户容易误解为手掌接触

新交互：
- 左手点击一张卡，卡片粘在左手附近
- 右手点击一张卡，卡片粘在右手附近
- 双手向中间靠近，但手掌不需要接触
- 当两张卡本身接触时触发判定

反馈：
- 两卡接近时出现金色能量线
- 接近时轻微磁吸和放大
- 接触时星尘冲击
- 合法配对汇聚成星并消失
- 非法配对软弹开，卡片仍留在手上

验收日志：
- `feelHandSignal`
- `feelCardTap`
- `feelCardsTouch`
```

## Prompt 9：修复左右手识别

```text

请排查并修复：
- `GazePinch` 不携带手别

1. 读取左右手 pinch strength

日志必须输出：
- leftPinch / rightPinch
- leftAim / rightAim
- leftVisible / rightVisible
- occupiedLeft / occupiedRight
- 最终选择的手别

验收：
- 左手点第一张，右手点第二张
- 选错后可用同一只手点正确卡片替换
```

## Prompt 10：空间音效无声排查

```text
真机上所有音效完全无声，但系统媒体音量正常。

请排查：
1. SoundPool sample 是否加载成功
2. play 是否返回有效 stream id
3. AudioAttributes usage 是否被 PICO 过滤

要求：
- 给每个 sample 的 load 和 play 增加日志
- 音效使用 `AudioAttributes.USAGE_GAME`
- 不使用 `USAGE_ASSISTANCE_SONIFICATION`

日志格式：
```text
soundLoad sample=ui_click status=0
soundPlay sample=ui_click stream=123
```

验收：
- 卡片选中、按钮点击、匹配成功、失败、洗牌、通关均有声音
- 真机音量正常时无需额外设置即可听到
```
