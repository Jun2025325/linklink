# linklin：3D 空间连连看玩法说明

版本基线：`0.2.1-position-polish`  
平台：PICO Spatial / Full-space Stage  
核心形态：黑色宇宙空间中的 3D 动物卡片连连看

---

## 1. 游戏概述

linklin 是一款面向 PICO 真机的 3D 空间连连看游戏。

玩家在黑色宇宙空间中看到一组漂浮的动物卡片。卡片按三维网格排列，例如：

```text
4 × 4 × 4
```

玩家需要找到两张可以配对的卡片，并判断它们之间是否存在合法 3D 折线路径。配对成功后，两张卡片消失；清空全部卡片即通关。

与传统 2D 连连看相比，linklin 的主要差异是：

1. 卡片排列在三维立方体网格中，而不只是平面上。
2. 路径可以在 `X / Y / Z` 三个方向行走。
3. 玩家可以旋转游戏主体，从不同角度观察卡片。
4. UI 面板也悬浮在空间中，可以拖动位置、调整朝向。
5. 手感模式使用左右手各拿一张卡，通过双卡相碰确认配对。

---

## 2. 开始菜单与设置项

游戏首次进入时，会显示「开始 3D 连连看」设置面板。

### 2.1 预设难度

| 难度 | 网格 | 卡片数 | 配对数 | 空位 |
|---|---:|---:|---:|---:|
| 简单 | 3×3×3 | 26 张 | 13 对 | 1 个 |
| 普通 | 4×4×4 | 64 张 | 32 对 | 0 个 |
| 困难 | 5×5×5 | 124 张 | 62 对 | 1 个 |

说明：

- 奇数格子会出现空位，例如 3×3×3 有 27 个格子，但只放 26 张卡。
- 空位藏在立方体内部中间位置，保证从外面看仍是完整形状。
- 空位可以作为路径空间使用。

### 2.2 自定义难度

玩家可以自定义三个方向的边长：

```text
高度 × 宽度 × 深度
```

当前规则：

- 最小边长为 2。
- 边长不设上限。
- 奇数总格数会自动保留 1 个空位。
- 大棋盘会保持最小可点击卡片尺寸，不会无限缩小卡片。

自定义适合挑战更大的空间，但过大的棋盘会增加观察、寻找和性能压力。

### 2.3 模式

| 模式 | 定位 | 是否计时 | 核心交互 |
|---|---|---:|---|
| 休闲模式 | 传统连连看的 3D 升级版 | 否 | 眼神 / 射线点选卡片 |
| 手感模式 | 空间手部交互模式 | 否 | 左右手各粘一张卡，双卡相碰消除 |
| 限时挑战 | 在限时内完成全部消除 | 是 | 与休闲模式相同的点选操作 |

## 3. 模式玩法

### 3.1 休闲模式

休闲模式是最基础的玩法，不计时，适合慢慢观察和思考。

操作流程：

1. 用眼神或射线选中一张卡片。
2. 确认捏合或点击。
3. 第一张卡片会高亮并放大。
4. 再选择第二张卡片。
5. 如果两张卡相同，且存在合法路径，则消除。
6. 如果不满足条件，则取消当前选择。

特点：

- 没有时间压力。
- 没有生命值或失败惩罚。
- 可以随意旋转棋盘观察。
- 适合第一次体验游戏。

### 3.2 手感模式

手感模式强调真实手部交互。

基本流程：

1. 左手点一张卡，卡片粘在左手附近。
2. 右手点一张卡，卡片粘在右手附近。
3. 双手向中间靠近。
4. 当两张被拿起的卡片彼此接触时，触发配对判定。
5. 合法配对消失，非法配对软弹开。

重要规则：

```text
确认动作是两张卡相碰，不是两只手掌相碰。
```

因此玩家不需要真的拍掌，双手保持自然距离即可。

如果拿错卡：

1. 不需要把卡放回原位。
2. 用同一只手直接点正确的卡片。
3. 错误卡片会被替换。

如果点到自己手上已有的同一张卡，则会释放该卡。

当两张被拿起的卡逐渐接近时：

- 卡片之间出现金色能量线。
- 卡片轻微放大。
- 两卡之间有软磁吸效果。
- 接触时出现星尘冲击。

### 3.3 限时挑战

限时挑战使用与休闲模式相同的点选操作，但必须在时间耗尽前清空全部卡片。

时间规则：

```text
基础时间 90 秒
+ 每对 16 秒
再按 30 秒取整
最低不少于 3 分钟
```

常见难度时间：

| 难度 | 配对数 | 限时 |
|---|---:|---:|
| 3×3×3 | 13 对 | 05:00 |
| 4×4×4 | 32 对 | 10:00 |
| 5×5×5 | 62 对 | 18:00 |

菜单展开时，倒计时暂停。

如果时间归零时仍有卡片未消除：

- 棋盘隐藏。
- 工具按钮隐藏。
- 显示「时间到 / 挑战失败」面板。
- 玩家可以重新挑战或返回菜单。

## 4. 配对规则

两张卡片要消除，必须同时满足两个条件：

```text
1. 图形相同
2. 存在合法 3D 路径
```

图形身份由两部分组成：

```text
动物 + 底色
```

因此，两张卡必须：

- 动物相同。
- 底色相同。

例如：

```text
黄色猫 + 黄色猫 ✅ 可以配对
黄色猫 + 蓝色猫 ❌ 不能配对
黄色猫 + 黄色狗 ❌ 不能配对
```

## 5. 3D 路径规则

### 5.1 路径形态

两张可消除卡片之间必须存在一条折线路径。

路径可以：

- 沿 `X` 方向走。
- 沿 `Y` 方向走。
- 沿 `Z` 方向走。
- 在三个方向之间转弯。
- 绕到立方体外围空壳。

当前规则允许最多：

```text
3 个弯
```

这比传统连连看常见的 2 弯规则更宽松，适合 3D 空间中的观察和绕行。

### 5.2 可通过区域

路径可以通过：

1. 已被消除的空格子。
2. 奇数棋盘保留的内部空位。
3. 立方体外围一层 shell 空间。

路径不能穿过：

1. 仍然存在的卡片。
2. 不在合法网格 / 外壳范围内的区域。

### 5.3 直观理解

可以把棋盘想象成一个三维方块阵列。两张卡之间如果能用一条最多三段转弯的折线连起来，而且这条线不穿过其他卡，就可以消除。

示意：

```text
卡片 A ─────┐
            │
            └───── 卡片 B
```

在 3D 中，这条线还可以向前后方向绕行。

## 6. 卡片图形规律

### 6.1 动物

当前共有 8 种动物：

| 动物 | Emoji |
|---|---|
| 猫 | 🐱 |
| 狗 | 🐶 |
| 兔子 | 🐰 |
| 狐狸 | 🦊 |
| 熊 | 🐻 |
| 熊猫 | 🐼 |
| 青蛙 | 🐸 |
| 猴子 | 🐵 |

### 6.2 底色

每种动物搭配 8 种底色，形成 64 种图形身份。

底色大致分为：

| 类型 | 视觉感受 |
|---|---|
| 红色系 | 明亮、醒目 |
| 橙色系 | 温暖 |
| 绿色系 | 清新 |
| 蓝色系 | 冷静 |
| 紫色系 | 柔和 |
| 青色系 | 通透 |
| 金色系 | 高亮 |
| 灰蓝色系 | 低刺激 |

### 6.3 大棋盘重复规律

对于 3×3×3、4×4×4、5×5×5，卡片身份数量不超过 64 种。

更大的自定义棋盘会重复使用这些动物 / 底色组合，但重复时一定按完整对出现，保证每张卡都有可配对目标。

也就是说：

```text
同一身份可以出现多对，但不会出现孤立卡片。
```

### 6.4 渲染规律

每张卡片是一个 3D cube。

卡片纹理采用：

```text
一张卡 = 一个 cube = 一个完整纹理
```

纹理中一次性烘焙：

- 背景底色。
- 动物 emoji。
- 圆角边框。
- 选中态样式。

六个面使用同一套完整纹理，因此棋盘旋转时不会出现：

- 某一面动物丢失。
- 某一面底色不同步。
- 某一面没有选中态。

## 7. 游戏内功能按钮

游戏中右侧有四个常驻按钮：

| 按钮 | 功能 |
|---|---|
| 菜单 | 重新展开开始 / 设置面板 |
| 提示 | 高亮一组当前可消除的卡片 |
| 洗牌 | 重新排列剩余卡片 |
| 放弃 | 放弃当前局并重新开始 |

### 7.1 提示

每局默认有：

```text
3 次提示
```

点击提示后：

1. 找到一组当前可连接的卡片。
2. 两张卡高亮。
3. 显示一条较持久的蓝色引导路径。
4. 提示次数减少 1。

提示次数用完后按钮不可用。

### 7.2 洗牌

点击洗牌后：

- 剩余卡片重新排列。
- 已消除卡片不会恢复。
- 洗牌后保证至少存在可连接配对。
- 卡片以 3D 飞行轨迹移动。
- 飞行时有拖尾和音效。

洗牌不会重置提示次数。

### 7.3 放弃

点击放弃会结束当前局并重新开始，适用于：

- 当前局面不满意。
- 想重开同一难度。
- 想重新观察初始排列。

### 7.4 菜单

点击菜单后：

- 展开开始 / 设置面板。
- 棋盘隐藏。
- 工具按钮隐藏。
- 限时模式倒计时暂停。

玩家可以在菜单中：

- 切换难度。
- 切换模式。
- 重新开始游戏。
- 返回菜单。
- 退出游戏。

关闭菜单后回到游戏。

## 8. 空间操作说明

### 8.1 游戏主体

游戏主体即 3D 卡片棋盘。

当前交互规则：

```text
DirectPinch 拖动棋盘 = 移动棋盘位置
GazePinch / RayBasedPinch 拖动棋盘 = 旋转棋盘
```

也就是说：

- 用手直接捏住棋盘拖动，可以调整它在空间中的位置。
- 用眼神或射线拖动，可以旋转棋盘，从不同角度观察。

旋转可用于：

- 查看被前排遮挡的卡片。
- 观察立方体后方卡片。
- 寻找可连接路径。

### 8.2 开始面板与工具面板

开始面板、游戏内菜单和右侧工具面板都是空间 UI。

单手操作：

```text
捏住面板任意位置 → 拖动 → 移动面板位置
```

不需要点击专门的拖动把手。

双手操作：

```text
两只手同时捏住面板
```

双手可以同时调整：

1. 面板位置。
2. 面板角度。

| 双手动作 | 面板反馈 |
|---|---|
| 双手整体同向移动 | 面板位置移动 |
| 一手向前、一手向后 | 面板左右转向 |
| 一手向上、一手向下 | 面板俯仰变化 |

面板俯仰角有限制，避免翻到不可读。

## 9. 视觉与反馈

### 9.1 整体视觉

游戏使用统一的黑色宇宙风格：

- 黑色 / 深蓝黑星空背景。
- 深色玻璃空间面板。
- 淡蓝星光边框。
- 卡通动物卡片。
- 低饱和功能色按钮。

### 9.2 匹配成功

配对成功时：

1. 显示真实路径的发光星点。
2. 两张卡向中点汇聚。
3. 卡片缩小并消失。
4. 爆出星尘粒子。
5. 播放成功音效。
6. 连续成功会形成 combo。

### 9.3 匹配失败

配对失败时：

- 播放柔和失败音效。
- 手感模式中两张卡软弹开。
- 卡片不会丢失，可以继续替换。

### 9.4 Combo

短时间内连续成功消除会累计 combo：

```text
连击 ×2
连击 ×3
...
```

反馈包括：

- 浮动连击提示。
- 成功音效音高逐渐上升。
- 连击中断后重置。

## 10. 通关流程

当全部卡片消除完成后：

1. 显示「恭喜通关」。
2. 播放星座动画。
3. 播放烟花、礼炮和庆祝音效。
4. 播放中文语音「恭喜成功！」。
5. 庆祝结束后显示操作：
   - 下一关。
   - 返回菜单。

下一关会递增三个方向的边长：

```text
3×3×3 → 4×4×4 → 5×5×5 → 6×6×6 ...
```

没有固定上限。奇数边长关卡会继续自动保留一个内部空位。

## 11. 新手建议

### 11.1 从 3×3×3 开始

3×3×3 只有 13 对，适合熟悉：

- 3D 路径规则。
- 卡片旋转观察。
- 提示和洗牌。

### 11.2 先玩休闲模式

休闲模式不计时，适合慢慢理解 3D 路径。

### 11.3 善用旋转

如果找不到可连卡片，先旋转棋盘：

- 查看侧面。
- 查看后方。
- 确认是否有被遮挡的同类卡。

### 11.4 提示用于确认规则

当不确定两张卡是否能连时，可以先用提示观察系统选出的路径。

### 11.5 手感模式先练习粘卡

第一次玩手感模式时：

1. 先练习左手点一张、右手点一张。
2. 确认卡片能粘在对应手附近。
3. 再慢慢靠近，让两张卡接触。

不需要快速拍手。

## 12. 常见问题

### Q1：为什么两张动物相同但不能消除？

检查底色是否相同。配对要求动物和底色都相同。

### Q2：为什么看起来相邻但不能消除？

可能存在其他卡片阻挡。3D 中还需要考虑深度方向和路径转弯数。

### Q3：3×3×3 为什么不是 27 张卡？

27 是奇数，无法全部成对。游戏保留 26 张卡和 1 个内部空位。

### Q4：手感模式需要拍掌吗？

不需要。当前规则是两张被拿起的卡片相碰，不是手掌相碰。

### Q5：限时模式菜单打开时会计时吗？

不会。菜单展开时倒计时暂停。

### Q6：自定义棋盘可以多大？

边长不设上限，但过大的棋盘会增加寻找难度和性能压力。

找到动物和底色都相同的两张卡，
并通过最多三弯的 3D 折线路径将它们消除，
直到清空整个立方体。
